3 · Garantías de apagado (5 capas)

No depende de una sola cosa: aunque mi sesión se caiga, el script falle y la red se corte, la VM se borra sola.

  1. Auto-borrado forzado por GCP (garantía de infraestructura)--max-run-duration=21600s + --instance-termination-action=DELETE → GCP elimina la VM a las 6 h pase lo que pase, aunque todo lo demás falle. Es el techo duro del costo.
  2. Auto-eliminación al terminar el trabajoEl script de arranque, al subir los resultados a GCS, ejecuta gcloud compute instances delete de sí mismo → la VM se borra apenas termina (~2–3 h, mucho antes del tope).
  3. Preempción Spot = otro apagadoSi GCP recupera la VM Spot, con la acción DELETE también se elimina (no queda apagada facturando disco).
  4. Verificación activa míaAl terminar corro gcloud compute instances list y te muestro “0 instancias”. Si algo quedara, lo borro explícito en el acto.
  5. Cero recursos residualesSin IP estática, sin snapshots, sin discos extra. El disco de arranque se borra junto con la VM (auto-delete). Nada sobrevive para facturar.
